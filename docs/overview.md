# Overview

## Learning Objectives

This lab provides a hands-on introduction to designing, deploying, and managing Autonomous Webex AI Agents and integrating advanced AI tools within Webex Contact Center (WxCC). Across six practical modules, you will explore how AI transforms customer interactions, agent workflows, and system administration:

* **Autonomous AI Agent Setup (Lab 1):** Learn the fundamentals of building an AI agent from scratch, connecting it to a knowledge repository, and configuring it to answer customer inquiries accurately using underlying knowledge sources.


* **API Integration via Webex Connect (Lab 2):** Discover how to extend an AI agent's capabilities by configuring Webex Connect flows to interact with external APIs and third-party systems.


* **Voice Flow Creation & Escalation (Lab 3):** Design voice interactions for phone calls, test real-time AI voice conversations, and experience how conversation summaries seamlessly transfer context when escalations reach human agents.


* **AI-Powered Quality Management & Coaching (Lab 4):** Step into a supervisor role using AI Quality Management tools to analyze low customer satisfaction scores, identify agent coaching needs, and improve overall contact center performance.


* **Enterprise System Integration via MCP (Lab 5):** Connect external backend systems—such as an order management system deployed via a Model Context Protocol (MCP) server—to handle omnichannel customer inquiries across chat and voice.


* **Developer Tooling & Platform Operations (Lab 6):** Act as a Solutions Architect to integrate WxCC platform and operational telemetry MCP servers into AI developer clients, perform administrative tasks using natural language queries, and execute draft flow updates.
